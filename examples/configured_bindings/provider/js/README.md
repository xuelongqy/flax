# Configured Prices SDK

`@example/prices/api` exposes the Money binding owned by the configured_prices Dart
package. Install the public types package for compilation. The Flax host prepares this
private local runtime package and registers the provider's Dart bindings. Only the
declarations in `../js-types` are packed for npm delivery.

This fixture uses local archives and version 0.0.0. No packages are published.
