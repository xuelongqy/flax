# Active Tasks

[Binding Coverage Expansion](binding-coverage-expansion-v1.md) is the current binding
worklist. It combines remaining generator gaps, explicit selection candidates, the
outside-library pilot and undecided automation/package-management questions.

Current behavior belongs in [architecture](../architecture/README.md), capability status
in the [coverage map](../architecture/binding-coverage-map.md), validation scope in the
[compatibility matrix](../architecture/external-binding-compatibility.md), and unsettled
decisions in [Open Questions](../decisions/open-questions.md).

Use the [task template](TEMPLATE.md) only when unfinished work needs a durable handoff.
Keep one concise record with scope, evidence, blockers and next steps. On completion,
move lasting contracts and reproduction instructions to the owning documentation, then
remove the completed task body. Do not create a permanent archive of iteration logs.
Disposable notes and local receipts belong in `.local/`; never copy private prompts,
credentials or conversation transcripts into repository documentation.
