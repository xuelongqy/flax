# Binding Rules

Reserved rule groups:

- [Flutter base APIs](flutter/README.md)
- [Material UI](material_ui/README.md)
- [Cupertino UI](cupertino_ui/README.md)

This directory will own generation inputs and exceptional adaptation rules. Generated
code belongs in the corresponding Dart and JS packages.

No configuration schema, binding protocol, or working generator command is defined in
this scaffold. Read [generation design](../docs/architecture/bindings.md) and
[local agent guidance](AGENTS.md) before adding either.
