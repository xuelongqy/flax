# flax_engine_hermes

Intended responsibility: Distribution and creation of a Hermes-backed native runtime
through the eventual host interface.

Status: empty library scaffold. There is no public API or working runtime. The package
is version 0.0.0 and publication is disabled.

There is no build hook, native artifact, engine download, or runtime factory. Hermes is
not selected as the default engine.

See [architecture](../../docs/architecture/README.md) and
[scoped checks](../../CONTRIBUTING.md#checks).
