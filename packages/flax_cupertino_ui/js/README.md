# @flax/cupertino-ui-runtime

Runtime source for the public `@flax/cupertino-ui` module.

The package contains runtime ESM and the module-delivery manifest used by Flax host
assets. Public declarations live in `@flax/cupertino-ui`. Shared Flutter values are
imported from their existing providers.

See [architecture](../../../docs/architecture/README.md) and
[scoped checks](../../../CONTRIBUTING.md#checks).
